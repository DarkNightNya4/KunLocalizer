# KunLocalizer

WoW 3.3.5a (12340 / Interface 30300). 作者 Delete (darknightnya4)。

Grimfall 英文 → 简体中文试用样本，覆盖 5 个对象的 35 条译文。退出游戏，将 KunLocalizer 和 KunLocalizer_Grimfall_zhCN 两个目录放到 Interface/AddOns。已有坤盒项目语言包的玩家可仅启用自己的项目包，避免同一内容加载两份配置。

进入角色后输入 `/kunloc`。可悬停火舌武器（技能 16342）、法力之怒（物品 27899）、符文刃舞（技能 49028）、深寒符文（2594）或屠戮（天赋 48979）。内置译文可离线显示。遇到异常请反馈客户端版本、对象 ID 和局部截图，也可从坤盒的插件报错日志复制对应记录。
